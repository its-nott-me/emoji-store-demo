# EmojiStore Demo App

This is a demo application showcasing the [react-emoji-store](https://www.npmjs.com/package/react-emoji-store) npm package. It demonstrates how to easily render Microsoft Fluent Animated Emojis in a React application.

## Features

- **Animated Emojis**: Beautifully rendered Microsoft Fluent emojis.
- **Live Preview**: Real-time rendering of emojis within text using the `<TextWithEmoji />` component.
- **Skin Tone Support**: Built-in support for multiple skin tone variations.
- **Automatic Fallback**: Graceful fallback to native system emojis if assets are missing.
